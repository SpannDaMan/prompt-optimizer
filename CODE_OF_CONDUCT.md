# Code of Conduct

We want Prompt Optimizer to be a useful, respectful developer community.

Be constructive, specific, and evidence-oriented. Critique code and behavior rather than people. Respect privacy, licenses, identities, experience levels, and good-faith disagreement. Do not harass, threaten, discriminate, expose private information, or use project spaces for spam.

Maintainers may edit or remove content and restrict participation when conduct undermines a safe, productive project. Report conduct concerns through the private channel described in `SECURITY.md`; do not post sensitive evidence publicly.

Enforcement decisions should be proportionate, documented, and limited to project spaces.
