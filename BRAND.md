# Prompt Optimizer Brand

## Promise

Compile clearly. Verify locally.

## Personality

Precise, calm, technical, and honest about the line between semantic judgment and deterministic proof.

## Mark idea

A microphone and living waveform resolve into aligned prompt bars. The silhouette communicates spoken or messy instructions becoming an organized prompt packet, not a podcast, voice assistant, recording app, magic wand, brain, robot, or sparkle cloud.

The microphone is an input metaphor: Prompt Optimizer compiles the text supplied by a host interface and does not implement audio recording or speech recognition.

## Voice
