# Provenance

Prompt Optimizer is a clean-room public implementation of a generic product contract: compile long agent requests while preserving source constraints and authority boundaries.

The candidate was written from scratch for this repository. It does not copy source code, prompts, private paths, credentials, client content, model routes, evaluation fixtures, or Git history from an external repository or a private operating system.

Public references were used only to understand category boundaries and current user expectations. They are not code or prompt sources:

- OpenAI prompt management and model guidance.
- promptfoo's public repository and documentation.
- linshenkx/prompt-optimizer's public repository description.

Prompt Optimizer is not affiliated with or endorsed by those projects or their maintainers.
